M.E.G.A Client

Client-side Fabric mod for Minecraft 1.21.11. ESP, tracers, X-ray, farm alerts and a block counter for the server. It only reads what the server already sends your game, and it never acts for you.

Spawner texture

Your design. Only players with M.E.G.A see it. Edit it in the spawner editor and send the new code to change it.

Everything it does

  • Player warning banner when another player is in sight; player list with name, distance and direction, no coordinates.
  • Block radar list: nearest targets with arrow, distance, coordinates and block name.
  • Tracers and boxes through walls to the nearest 8 targets, in their group colour.
  • Ore and valuable-block finder across your whole render distance (up to 1250 blocks).
  • Farm alert banner: built plant farms, machinery below y=0, and 32+ moving items (stone, cobble, deepslate and gravel ignored).
  • Blocks seen panel: how many of each block type are in range.
  • M.E.G.A X-ray: hides everything else, keeps important blocks textured, outlines cave walls near you.
  • Ignore list: IzzosBro2013 (and you) are never detected.

Server rules

  1. No griefing
  2. No spawn camping
  3. No TP killing
  4. ESPs are allowed only after the owner has checked them. The HUD shows the version (M.E.G.A v0.18.1) so it can be checked.
  5. Duping is allowed only while the owner is watching.

Install

  • Install Fabric Loader for 1.21.11 and put Fabric API for 1.21.11 in .minecraft/mods.
  • Put mega-client-0.18.1.jar in the same folder and launch the Fabric profile.
Limits: it only sees chunks your game has loaded, can't read chest contents until opened, and an anti-xray plugin on the server will show fake ores. X-ray block hiding doesn't work alongside Sodium.
